# Zanzlanz-physics-engine-Phython-edition-
Hello Zanzlanz fans, I am EastMacaroon453! This is a rewrite of Zanzlanz's physics engine in Python. I had already rewrote his engine on Scratch so why leave Python out? Spawn circles with E-R-T, move circles around by pressing and holding them, and change scenes with the number keys. You can also make your own scenes!
